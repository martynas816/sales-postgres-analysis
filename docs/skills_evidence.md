# Data skills evidence map

This repo is designed to mirror the day-to-day work expected in junior Data Analyst / Analytics Engineer role:

- **SQL analytics (joins, windows, KPI reporting)** → `sql/06_analytics_queries.sql`, `sql/07_daily_commercial_questions.sql`
- **Reliable reporting numbers (definitions + validation)** → `docs/support_playbook/README.md` (definitions + checks), `sql/07_daily_commercial_questions.sql` (sanity checks)
- **Data modeling (star schema, facts/dims, grain)** → `sql/05_build_star_schema.sql` + README “Data model” section
- **Dashboards / stakeholder-ready outputs** → `outputs/*.png` (Metabase dashboards) + `outputs/outputs.md` (saved results)
- **Operating mindset (debugging + prevention)** → `docs/ops/incident_example.md`

## Where to look first (2 minutes)
1. `README.md` (quickstart + schema overview)
2. `outputs/01-dashboard-overall.png` (what a stakeholder sees)
3. `docs/support_playbook/README.md` + `sql/07_daily_commercial_questions.sql` (daily questions + how I validate)
4. `sql/05_build_star_schema.sql` (modeling)
